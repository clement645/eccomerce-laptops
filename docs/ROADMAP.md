# Implementation roadmap

Each phase ends with a report: completed work, files changed, decisions, tests actually executed, open issues, verification steps, and the next phase.

| Phase                                  | Scope                                                                                                                                                                                                                                                                              | Exit criteria (deliverable)                                                                   |
| -------------------------------------- | ---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | --------------------------------------------------------------------------------------------- |
| **1. Foundation**                      | pnpm monorepo, TS config, shared packages, Nest/Next/Vue skeletons, Tailwind 4, ESLint/Prettier, Docker (Postgres, Redis, RustFS, Mailpit), env templates, ADRs                                                                                                                    | All three apps start; build, lint, typecheck, and tests pass from the root.                   |
| **2. Database and backend foundation** | `@repo/database` (Prisma 7, Neon adapter, pooled/direct URLs), full schema + migrations + raw-SQL check constraints, seed (categories, brands, realistic products, roles/permissions), Prisma/Redis modules, readiness health, Swagger, error envelope, Zod pipe, rate-limit guard | `pnpm db:migrate && pnpm db:seed` works locally; integration tests run against the Docker DB. |
| **3. Storefront UI**                   | Design system components; header, announcement bar, hero carousel, trust cards, categories, promo banners, product cards, brand showcase, testimonials, blog preview, newsletter, footer                                                                                           | Responsive homepage on seed data, checked against the reference screenshot.                   |
| **4. Product catalog**                 | Catalog/category/brand APIs with caching; PLP with filters, sort, and pagination; PDP with gallery, zoom, specs, and variants; full-text search + autocomplete (`pg_trgm` for typos); SEO (metadata, JSON-LD, sitemap)                                                             | Catalog served from Postgres via the API, with cache invalidation tested.                     |
| **5. Authentication**                  | Register, verify email, login, logout, refresh rotation with reuse detection, password reset, profile and addresses, admin login + TOTP MFA, RBAC guards, audit log                                                                                                                | Auth and authorization test suites pass.                                                      |
| **6. Cart and checkout**               | Guest and user carts with merge, pricing engine (server-side), shipping rates by county/town, multi-step checkout, order creation, stock reservation + expiry job, simulated payment provider                                                                                      | Concurrency test proves no oversell; checkout E2E passes with a mock provider.                |
| **7. Payments**                        | Provider abstraction, M-Pesa STK Push/callback/STK Query reconciliation, timeouts, idempotency, COD rules, card adapter interface (hosted checkout), refund foundations                                                                                                            | Sandbox-tested; callback spoofing and duplicate tests pass. No live credentials.              |
| **8. Admin dashboard**                 | Auth/MFA screens, overview analytics (real queries), product editor with R2 uploads, categories, brands, inventory, orders and state machine, customers, banners/homepage, roles                                                                                                   | Admin E2E: create a product, then fulfil an order.                                            |
| **9. Content and advanced**            | Blog CMS (sanitized rich text, scheduling), reviews + moderation, coupons, newsletter (double opt-in), email notifications via the worker, contact page, store settings                                                                                                            | Feature tests pass; emails visible in Mailpit.                                                |
| **10. Hardening**                      | Security review (OWASP ASVS), authz matrix tests, payment abuse tests, load/concurrency tests, a11y (axe), Lighthouse, full Playwright journey                                                                                                                                     | Release candidate plus a documented list of known issues.                                     |
| **11. Deployment**                     | Netlify configs, API Dockerfile and host config, Neon prod + migration workflow, Redis, R2 buckets/CORS/custom domain, GitHub Actions CI/CD, health checks, monitoring, backups/PITR runbook                                                                                       | Documented and repeatable deployment.                                                         |
